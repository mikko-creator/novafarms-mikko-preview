# novafarms preview (personal)

Static preview of a site rebuild, published for visual review only.

**This is not the live site**, and it is not the team's shared preview. It is a
point-in-time snapshot of one working branch, kept so the changes on that branch
can be looked at in a browser.

All pages are `noindex` and `robots.txt` disallows crawling.

Internal working documents, audit data and build tooling are deliberately not
included here — this repository holds only what is needed to render the pages.
